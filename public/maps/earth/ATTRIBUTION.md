# Earth surface assets

Earth day, night and combined bump/roughness/cloud textures are from the Three.js Earth example, based on Solar System Scope textures (CC BY 4.0).

- Original author: Solar System Scope / INOVE, https://www.solarsystemscope.com/textures/
- License: https://creativecommons.org/licenses/by/4.0/
- Distributed resized/combined versions: https://github.com/mrdoob/three.js/tree/dev/examples/textures/planets
- Local rendering applies terrain shading and time-dependent illumination; images themselves are unchanged.

Solar position uses the NOAA approximation: https://gml.noaa.gov/grad/solcalc/solareqns.PDF
Night imagery is a static geographic distribution, not live city power/weather data. Relief shading is not a survey-grade elevation model.
